### Where to look when something breaks

| Symptom                                     | Link to inspect      | Usual cause                                                                        |
| ------------------------------------------- | -------------------- | ---------------------------------------------------------------------------------- |
| All backends unhealthy, app works fine      | Firewall, not the LB | No rule allowing `35.191.0.0/16` and `130.211.0.0/22` on the probe port            |
| Certificate errors                          | Target proxy         | Self-managed cert expired, or the domain is not on the cert                        |
| Requests hitting the wrong service          | URL map              | Host or path matcher order, or a missing default service                           |
| WAF rules never fire                        | Backend service      | No policy attached, or traffic is arriving by a path that bypasses the LB entirely |
| App logs the same client IP for everything  | Nothing is broken    | Proxy LB, so the app must read `X-Forwarded-For` instead of the TCP source         |
| Backend serves errors but stays in rotation | Backend service      | TCP health check — the port is open, so it passes while the app is broken          |
